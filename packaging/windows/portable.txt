Prckopis portable mode

While this file sits next to prckopis.exe, Prckopis keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PrckopisData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Prckopis with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Prckopis and
%LOCALAPPDATA%\Prckopis) instead. If PrckopisData can't be written (for example on a read-only
drive), Prckopis says so and uses the per-user folders instead.
